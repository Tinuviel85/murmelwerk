# GitHub Pages veröffentlichen

1. Repository öffnen: https://github.com/Tinuviel85/murmelwerk
2. **Settings** auswählen.
3. Unter **Code and automation** → **Pages** öffnen.
4. Unter **Build and deployment** als Source **Deploy from a branch** wählen.
5. Branch **main**, Ordner **/(root)** wählen.
6. **Save** drücken.

GitHub veröffentlicht dann die statische Anwendung unter:
`https://tinuviel85.github.io/murmelwerk/`

Falls die Webseite danach zunächst nicht erreichbar ist, den Veröffentlichungsstatus im selben Pages-Bereich kontrollieren. GitHub Pages muss im Repository aktiviert sein; diese Einstellung kann der verbundene Schreibzugriff nicht selbst setzen.
