# Murmelwerk

**Murmelwerk** ist ein experimenteller 3D-Generator für modulare Holzmurmelbahnen mit benutzerdefiniertem Teilebestand.

## Website
Die statische Anwendung wird über `index.html` gestartet. GitHub Pages kann dieses Repository ohne Server veröffentlichen.

## Projektstand
- Startversion: Quadrilla-Generator V13 (schematische 3D-Darstellung)
- Bauteilbestand frei einstellbar, 5–50 % Toleranz
- Neue Konstruktion per Klick, drehbare und verschiebbare Ansicht
- Grundraster: 12 mm; Standardblock: 44 × 44 × 60 mm, Zapfen: 12 mm
- Erfasste Wegbeziehungen: Naturholz, Gelb, Orange, Grün, Türkis, Blau, roter Verteiler
- Schienen: kurze und große Kurve, S-Schiene; Melodietreppe vorläufig

**Wichtig:** Die erzeugten Bauformen sind technische Prototypen, nicht vollständig mechanisch validierte Bauanleitungen. Schienenanschlüsse, Kollisionen, Spiralen und reale CAD-Geometrie müssen weiter geprüft werden. Bei seitlicher Ausleitung von oben sind Beschleunigerkeile nötig.

## Repository-Struktur
- `index.html`: bisherige lauffähige Web-App
- `data/`: maschinenlesbare Konstruktionsregeln
- `docs/ROADMAP.md`: Entwicklungsplan
- `archive/`: Referenz der letzten Standalone-Version
- `models/`: CAD-Referenzmodelle (sofern übertragen)

## Projektziele
Ein Inventarkatalog für alle Teile (nicht vorhandene Teile mit Menge 0), 3D-Darstellung, regelbasierte Konstruktion mit gültigen Kugelwegen und belastbaren Stützen. Aktiver Entwicklungsumfang: Endspurt, Cyclone und eine einzelne Melodietreppe.
